# 潮汐进化 0.8 自动平衡验证

使用真实游戏更新逻辑，比较 8 种构筑选择策略；最终复核 160 局、20 个未用于校准的随机种子。
在 20/20 个种子中找到了能通过六关的候选路线。以下数据按每个种子最快的完整通关候选路线统计，不能视为全局最优解或真人通关率。

| 关卡 | 固定限时 | 通关耗时中位数 | 剩余时间中位数 | 剩余时间范围 |
|---|---:|---:|---:|---:|
| 1 | 31 秒 | 11.1 秒 | 19.9 秒 | 14.1–25.6 秒 |
| 2 | 41 秒 | 19.9 秒 | 21.1 秒 | 11.8–29.1 秒 |
| 3 | 41 秒 | 26.6 秒 | 14.4 秒 | 1.5–30.2 秒 |
| 4 | 49 秒 | 27.8 秒 | 21.2 秒 | 13.8–30.3 秒 |
| 5 | 59 秒 | 37.0 秒 | 22.0 秒 | 5.1–30.4 秒 |
| 6 | 67 秒 | 44.8 秒 | 22.2 秒 | 12.9–31.9 秒 |

## 修改

- 漩涡基础范围 180 → 125，吸力 245 → 170；范围强化每次 +24，最大 185，持续时间最大 2 秒。
- 第二关以后普通鱼成长 0.7 → 0.5；第一关保留 0.7。高效消化每次 +12%，总进食倍率最高 1.6；乘流进食加成 60% → 25%。
- 声波、初始体型、护泡和加时增加叠加上限，防止越到后面收益失控。
- Boss 生命为 60/125/175/240/330/450；中后期增加三轮扫射、旋转针刺、交错弹幕与陷阱组合。
- 逐关限时依据最快成功候选路线的通关耗时加约 20 秒校准，随后用不同种子复核。

## 边界

机器人每 1/6 秒决策，使用同一移动、碰撞、冷却、奖励随机性和跨关能力累积逻辑。它不模拟鼠标精度、学习困惑或所有操作失误。固定参数不会保证每次通关都恰好剩 20 秒；不同构筑和随机种子仍有差异。

## 复现

在安装 Godot 的环境运行：
```sh
godot --headless --path game -- --simulate --samples=20 --seed-start=9000 --report=balance-v8-final
godot --headless --path game -- --self-test
godot --headless --path game -- --balance-test
```
